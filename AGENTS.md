# AGENTS.md

This repository's canonical agent and contributor instructions live in
**[`CLAUDE.md`](CLAUDE.md)**.

If you are a coding agent (Claude Code or otherwise), read `CLAUDE.md` first: it
contains the project overview, the architecture invariants you must never
violate, the repo map, the tech stack, and the workflow rules (gitflow,
Conventional Commits with DCO sign-off, the definition of done, and the list of
things you must never do).

Path-scoped rules live in [`.claude/rules/`](.claude/rules/) and apply to the
directories they name. Reusable workflows live in
[`.claude/skills/`](.claude/skills/).
