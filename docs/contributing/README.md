# Contributing docs

Contributor-facing documentation: the development environment (devcontainer,
`mise`, the `make` verbs), the gitflow branching model, Conventional Commits +
DCO sign-off, and the definition of done.

The canonical, concise contributor rules live in the repo-root
[`CONTRIBUTING.md`](../../CONTRIBUTING.md) and [`CLAUDE.md`](../../CLAUDE.md);
this section expands them with tutorials and deeper how-tos as the project grows.
